# BTCINAI

**B**itcoin **i**s **n**ot **a**n **i**nvestment — a single-page essay on what most people get wrong about Bitcoin.

**Live:** https://benjaminthedonkey.github.io/BTCINAI/

## Contents

- `index.html` — the whole site: markup, styles, and script in one self-contained file.

No build step and no dependencies beyond Google Fonts, loaded from a CDN.

## Local preview

Open the file directly:

```bash
open index.html
```

Or serve it:

```bash
python3 -m http.server 8000
```

## Deploying

GitHub Pages serves `main` at the repo root. Pushing to `main` publishes.
